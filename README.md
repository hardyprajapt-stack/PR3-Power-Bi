# Olist E-Commerce Power BI Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze Olist E-Commerce sales data. It provides insights into orders, revenue, customers, sellers, payments, products, and customer reviews.

## 📄 Dashboard Pages

### 1. Sales Overview
- Total Orders
- Total Revenue
- Average Order Value
- Average Customer Rating
- Top 10 Product Categories
- Monthly Orders Trend
- Year, Order Status and Product Category slicers

### 2. Geographic Analysis
- Top 10 Seller Cities by Revenue
- Revenue by Seller State
- Orders by Customer State
- Year slicer
- Customer and Seller geographical analysis

### 3. Payments & Reviews
- Payment Type by Year Matrix
- Payment Type Mix
- Average Review Score by Product Category
- Year slicer
- Customer satisfaction analysis

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 🔄 Data Preparation

The data was cleaned and transformed using Power Query. Relationships were created between fact and dimension tables to support accurate analysis and interactive filtering.

## 🎯 Project Objectives

- Analyze overall sales performance
- Identify top product categories
- Track monthly orders
- Analyze customer and seller locations
- Understand payment preferences
- Measure customer satisfaction
- Create an interactive business dashboard

## 📌 Key Features

- Interactive KPI Cards
- Slicers
- Bar and Column Charts
- Line Chart with Drill-down
- Map Visualization
- Matrix
- Donut Chart
- Dynamic DAX Measures
